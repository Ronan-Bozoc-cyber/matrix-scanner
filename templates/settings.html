Paramètres & Privilèges Système (Sudo)

Certains outils réseau avancés comme Netdiscover (paquets ARP bruts) ou Nmap OS Detection nécessitent des privilèges d'administration (Root/Sudo). Saisissez votre mot de passe sudo pour autoriser l'exécution automatique en mode élevé.

Configuration Privilèges Sudo

Alternative sans mot de passe (Méthode Linux recommandée)

Pour éviter de stocker ou saisir votre mot de passe dans l'application web, vous pouvez accorder les capacités réseau à Netdiscover une fois pour toutes dans votre terminal :

sudo setcap cap_net_raw,cap_net_admin=eip /usr/sbin/netdiscover
