Explication : Envoie des requêtes ARP sur le réseau local pour découvrir les hôtes actifs, même s'ils bloquent le ping (ICMP).

Enregistrement du Nom de Domaine (WHOIS)

Commande : whois <domaine>
Explication : Interroge les bases de données publiques des bureaux d'enregistrement (registrars) pour obtenir des informations sur le propriétaire, la création du domaine et les serveurs DNS.

Explication : Utilise l'OSINT (moteurs de recherche, archives) pour énumérer passivement les sous-domaines existants sans attaquer directement la cible.

Pare-Feu Applicatif Web (WAF)

Commande : wafw00f https://<cible> -a
Explication : Envoie des requêtes HTTP malveillantes (patterns connus) pour détecter la présence et la marque d'un pare-feu applicatif web (WAF) tel que Cloudflare ou ModSecurity.
Analyse WAF avec Wafw00f en cours...

Capture d'Écran du Site Web Cible

Commande : gowitness single https://<cible> --disable-logging
Explication : Lance un navigateur "Headless" (sans interface) pour capturer l'apparence visuelle du site web et générer une preuve visuelle de son état initial.
Prise de vue du site web avec Gowitness en cours...

Empreinte CMS & Technologies Web (WhatWeb)

Commande : whatweb -a 3 https://<cible>
Explication : Analyse les en-têtes HTTP, cookies et code source HTML avec une agressivité de niveau 3 pour identifier précisément le CMS (ex: WordPress), les bibliothèques JS et les serveurs web.
Analyse des technologies et du CMS avec WhatWeb en cours...

Audit de Failles Récentes (Nuclei)

Commande : nuclei -u https://<cible> -t cves/ -t vulnerabilities/ -severity critical,high
Explication : Si aucun CMS n'est détecté, Nuclei utilise des modèles YAML (templates) pour tester rapidement des milliers de vulnérabilités connues (CVEs, 0-days) sur l'application cible.
Recherche de failles avec modèles (Nuclei) en cours...

Exploration & Fuzzing d'Arborescence Web (Gobuster)

Commande : gobuster dir -u https://<cible> -w /usr/share/wordlists/dirb/common.txt -q
Explication : Fuzzing par dictionnaire de l'arborescence web pour découvrir des répertoires d'administration, des sauvegardes, ou des fichiers cachés inattendus (Force Brute).

Audit de Sécurité Base de Données (SQLMap / NoSQLMap)

Explication : ParamSpider extrait toutes les URLs paramétrées des archives web, puis SQLMap les attaque massivement pour automatiser la détection et l'exploitation de failles d'injections SQL.
