Espace Pédagogique - Matrix Scanner

Cet outil a été conçu dans un but éducatif pour comprendre l'enchaînement des outils lors d'un test d'intrusion. Voici les deux chaînes de traitement automatisées (Workflows) disponibles.

Workflow : Scanner Distant (Web & Application)

Cible Web
Domaine & Sous-domaines (whois & Sublist3r)
Détection WAF (Wafw00f)
Empreinte (WhatWeb)
Capture (Gowitness)
Failles Web (Nikto, Nuclei, WPScan)

Workflow externe automatisé : Interroge le registre WHOIS et énumère les sous-domaines (Sublist3r), analyse la présence d'un pare-feu applicatif (WAF), capture l'aperçu visuel (Gowitness), identifie les technologies web (WhatWeb) et sonde les vulnérabilités serveur/web (Nikto, Nuclei, WPScan).

Workflow : Scanner Local (Intranet & LAN)

Cible LAN
Découverte ARP (Netdiscover)
Identité & NetBIOS (mDNS & nbtscan)
Ports & OS (Nmap)
Énumération SMB (Enum4linux, SMBMap)
CVE & Exploits (Exploit-DB)

Workflow interne automatisé : Cartographie les équipements (IP/MAC) via ARP (Netdiscover), identifie la marque/catégorie via NetBIOS/mDNS, sonde les ports et OS (Nmap), énumère les partages Windows/Samba (Enum4linux, SMBMap) et croise les bannières avec la base d'exploits (Searchsploit/CVE).
